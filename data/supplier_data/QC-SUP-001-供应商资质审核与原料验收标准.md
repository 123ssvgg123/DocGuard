# 供应商资质审核与原料验收标准

文件编号：QC-SUP-001
文件名称：供应商资质审核与原料验收标准
归口部门：集团品控部门
版本号：V4.0
生效日期：2024-03-01

## 一、供应商准入资质清单

### 通用资质（所有供应商必查项）

1. 营业执照（在有效期内，经营范围覆盖供应品类）
2. 食品生产许可证（SC 证）或食品经营许可证
3. 产品检验合格证明（每批次提供，或提供年度第三方检测报告）
4. 生产/经营场所的食品安全管理制度文件
5. 上一年度的监管抽检无不合格记录证明

### 分类资质要求

肉类供应商：另需提供动物防疫条件合格证、生猪定点屠宰证明、检疫合格证明（每批）、非洲猪瘟检测报告。

水产品供应商：另需提供水产养殖证或捕捞证明、产地证明、水产防疫合格证明。

蔬菜水果供应商：另需提供产地证明或种植基地备案证明，高风险品种（韭菜、豇豆、芹菜、普通白菜）需提供农残检测报告。

粮油副食供应商：另需提供生产许可证、产品标准号、年度型式检验报告。

冷链物流服务商：另需提供冷链运输资质、车辆制冷设备检定证明、全程温度监控记录能力说明。

## 二、供应商审核评分标准

| 评分项 | 权重 | 评分要点 |
|--------|------|----------|
| 资质完整性 | 25% | 上述资质文件齐全、均在有效期内 |
| 产品合格率 | 30% | 近 12 个月到货验收合格率、抽检合格率 |
| 检测能力 | 15% | 是否具备自检能力或稳定第三方检测合作 |
| 冷链保障 | 15% | 运输全程温度可控、有记录、无断链 |
| 追溯能力 | 10% | 批次可追溯、台账完整、响应及时 |
| 整改配合度 | 5% | 不合格品处置配合度、整改及时性 |

评分 90 分以上为 A 级（优先采购），75～89 分为 B 级（正常采购），60～74 分为 C 级（限制采购、限期整改），60 分以下为 D 级（列入不合格供应商名单，暂停合作）。

## 三、原料验收标准

### 肉类

1. 感官：色泽鲜亮，肌肉有弹性，无异味，无异常渗出物，无淤血、淋巴结残留。
2. 温度：冷藏肉到货中心温度 ≤4℃；冷冻肉到货中心温度 ≤-15℃。
3. 证照：检疫合格证明、检验合格证明随货同行，票证货相符。
4. 包装：无破损、无渗漏，标签信息完整（品名、生产日期、保质期、储存条件、生产者信息）。

### 水产品

1. 感官：眼球饱满凸出、鳃丝鲜红、肌肉紧实有弹性、无异味；冷冻品无反复冻融痕迹（无大量冰霜、无干缩）。
2. 温度：冷藏水产 ≤4℃；冷冻水产 ≤-15℃。
3. 禁止采购：河豚（除国家批准的养殖河豚加工产品）、来源不明的水产品。

### 蔬菜水果

1. 感官：新鲜，无腐烂、无霉变、无异味，无明显虫蛀与病斑。
2. 农残：高风险品种需提供快检或检测报告，快检抑制率 <50%。
3. 包装运输：使用清洁容器，不得与有毒有害物品混装。

### 粮油副食

1. 预包装食品标签符合 GB 7718 要求，标注生产日期、保质期、配料表、营养成分表。
2. 剩余保质期不低于总保质期的 2/3。
3. 食用植物油应查验酸价、过氧化值合格证明。

## 四、不合格品处置要求

1. 验收环节发现不合格的，一律拒收，填写《不合格品处理记录》，记录批次、数量、不合格项、处置结果。
2. 已入库后发现不合格的，立即隔离、挂牌标识、上报品控部门，不得擅自使用或降级使用。
3. 同一供应商连续 2 次出现同类不合格的，暂停合作并重新审核。
4. 涉及食品安全事故的供应商，立即列入不合格供应商名单，永久停止合作，并按规定报监管部门。
5. 供应商审核档案保存期限不少于 3 年。
