# ============================================================
# 关于 torch 的安装说明（重要）
# ============================================================
# torch 的构建版本（CUDA / CPU）取决于你的显卡与驱动，不能由 requirements.txt
# 统一决定，官方要求按 CUDA 版本走独立 index-url 安装。因此：
#
#   • 有 NVIDIA 显卡、要用 GPU 训练/推理：
#     ⚠️ 各 CUDA 源上的 torch 版本并不齐全，2.10.0 只在 cu126 / cu128 / cu130 上有，
#        cu121 最高 2.5.1、cu124 最高 2.6.0、cu129 最高 2.9.0。
#        按 torch 版本选源（不要按驱动版本选），实测可用命令：
#       CUDA 12.6 → pip install torch==2.10.0 --index-url https://download.pytorch.org/whl/cu126
#       CUDA 12.8 → pip install torch==2.10.0 --index-url https://download.pytorch.org/whl/cu128  ← 本机用这个
#       CUDA 13.0 → pip install torch==2.10.0 --index-url https://download.pytorch.org/whl/cu130
#
#   • 只用 CPU：
#       pip install torch==2.10.0 --index-url https://download.pytorch.org/whl/cpu
#
# 装完务必验证：
#     python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#     CUDA 版期望输出形如：2.10.0+cu128 True
#     CPU  版期望输出形如：2.10.0+cpu   False
#
# 注意：版本号没有 +cpu 后缀，不代表就是 CUDA 版——务必用上面的命令实测
#      torch.cuda.is_available()，避免「以为在用 GPU、其实一直跑在 CPU」。
#
# 项目代码不依赖具体是哪个构建：base/config.py 的 resolve_device() 会运行时
# 自动探测（cuda > mps > xpu > cpu），无需改代码即可在有卡的机器上吃到 GPU。
